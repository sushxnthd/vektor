## Bottleneck clusters
1. **Latency exposure:** dependency chains defeat traffic-only optimizations.
2. **State movement/locality:** divergence regrouping benefit is likely bounded by RF/cache movement cost.
3. **Scheduler locality:** fixed partitioning simplifies RTL but may strand issue bandwidth under correlated stalls.
4. **Physical feasibility:** architectural frequency/power/area targets remain unconstrained by technology-mapped evidence.

## Current experiment ranking
1. DISCRIMINATION: fixed 4x8 scheduler vs less-partitioned/global issue under readiness traces generated by memory/divergence models.
2. CAPABILITY-BUILDING: synthesizable per-wave scoreboard integrated with scheduler/RF arbitration.
3. SURPRISE: cheap randomized sweep across occupancy, memory latency, divergence geometry, RF banking and scheduler partitioning; reserve 10-15% search budget.
4. EXPLOITATION: operand-cache foothold boundary sweep over reuse distance and equal storage/banking budgets.

## Single next decisive action
Determine whether fixed scheduler partitioning is a structural utilization bottleneck once readiness is generated by the existing memory/divergence models. If yes, quantify the minimum cross-partition flexibility that recovers most of the global upper-bound utilization without paying full global-arbitration complexity.
