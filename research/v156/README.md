# V156 — first constrained OpenSTA timing comparison

Equal-latency buffered V151 vs V153 registered cutset at LANES=1. Use `bash research/v156/CI.sh` on an Ubuntu 22.04 runner with Yosys, Icarus and OpenSTA installed. This branch is a research experiment; the hypothesis may fail. Logs and netlists are saved as workflow artifacts on success or failure.

See `SCIENCE.md`, `ARCHITECTURE.md`, `PROTOCOL.md` and `build/v156/summary.json` in the CI artifact. No novel mechanism or GPU performance equivalence is claimed.
