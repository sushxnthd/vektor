# V292 — sparse-lane memory-return overlay (sole active kernel)

State: E0 hypothesis, no architecture improvement claimed. V287 and V291 are retired. **Not** an issue/ALU fusion mechanism: this candidate acts only on the L1-to-operand-collector *return* datapath.

1. **Bottleneck law:** fixed L-lane return bus wastes payload when sparse return masks are disjoint. For independent Bernoulli(q) lane masks, the probability that two masks are disjoint is e=(1-q^2)^L. With two waiting returns and two existing collector write destinations, raw packet throughput is at most 1+e returns/beat in the independent-pair approximation. If fraction p of *packets* are successfully paired, raw gain is 1/(1-p/2). Both formulas ignore selection correlation, metadata and wire delay.
2. **Exact mechanism:** when two pending returns have disjoint 32-lane valid masks, overlay their 32-bit per-lane payloads into one existing 1024-bit return bus beat, carrying both original warp tags and masks to two existing collector destinations. Never merge overlapping masks. Never reorder or discard unaccepted packets.
3. **Strongest equal-resource control:** a two-entry return queue with the same 1024-bit datapath, metadata bits, two collector destinations, comparator, and lane selection fabric, allowed to use conventional packing or sectorized delivery. A single-return controller is only a smoke-test lower bound; it is NOT a valid breakthrough baseline.
4. **Predicted boundary:** positive only when return bus is saturated, at least two pending returns exist, disjoint-mask probability is high, two collector destinations are free, and added tag/mask overhead plus mux delay fit the original cycle. No win when masks overlap, queue occupancy <2, collector writes limited to one, or upstream DRAM/L2 dominates.
5. **Smallest RTL:** purely combinational two-head admission and 32-lane overlay, no new queues or RF ports. Real synchronous collector handshakes and lane routing remain to be implemented.
6. **PPA gate:** synthesize overlay and strongest control at the same 1024-bit width; characterize mapped area, max-cap/slew, STA at realistic wire lengths/fanout, toggle-power proxy, 0.5x/1x/2x load sensitivity. If overhead erases service gain, kill.
7. **Workload metric:** accepted return packets per cycle, return payload bits/packet, end-to-end warp completion, collector occupancy and RF write traffic across compute, memory and divergent traces. Do not count empty lanes as useful data.
8. **Decisive falsification:** strongest equal-budget control matches throughput/energy or physical timing fails; or the actual V-Tile lacks two free collector write destinations or sparse return masks on this path.
9. **Unseen predictions:** frozen in FROZEN_PREDICTIONS.json before holdout evaluation. Training only at q=0.2 and 0.5.
10. **Architecture consequence:** only if gates pass, optional L1-to-collector overlay mux, never an FP32 lane/port increase. Otherwise V-Tile unchanged.

**Critical implementation question:** are return payloads already full cache-line sectors and is the collector path independently lane-addressable? If not, the hypothesized lane masks cannot be exploited without extra routing/storage and the kernel must be killed. No 5090-equivalence claim. Prior art must cover warp compaction, cache-sector responses and network flit packing before any novelty claim.
