# V296 parallel-threshold RTL topology trial — prospective protocol (2026-10-26)

## Single-mechanism scope
V296 pairwise bank-conflict arbitration remains the sole active architectural mechanism. V287 is retired. This trial is **only a logically equivalent combinational implementation** of V296, not a new scheduling policy, extra bank port, additional issue slot, or pipeline stage. The original RTL and negative integrated 3.5 ns results are immutable controls. Kernellum PR #119 is not touched.

## Before-outcome predictions and falsifiers
1. The new parallel conflict-threshold network must produce **exactly the same four grants** as the existing V296 greedy priority arbiter for all 16 validity masks and all ordered 4-request bank pairs drawn from banks {0,1,2}: 16 * 3^8 = 104,976 exhaustive cases. Add >=50,000 independent pseudorandom full-16-bank cases and bank-port accounting. A single mismatch kills this topology.
2. Parallel equality comparisons and explicit >=2-hit predicates might shorten the combinational grant cone relative to the original increment-based implementation, **but no timing or area win is presumed**. Record same-library mapped area and logic-depth proxies for the original V296, the trial and the serial one-hot control. If the new topology increases mapped area without a clear logic-depth benefit, reject it before integrated routing.
3. Frozen **predicted-win workload regime** for any future feasible clock advantage: 4 banks, p(valid)=0.95, within-request same-bank correlation rho=0.2, abundant bandwidth and high scheduler utilization. Frozen **predicted-no-win regime**: 16 banks, p=0.20, rho=0.2, memory bandwidth saturated. At equal clock and identical admission semantics, the prediction is **exactly zero V296-vs-control throughput gain in both regimes**. Any claimed performance gain must come from independently measured feasible clock/area effects and disappear at the bandwidth ceiling.
4. Passing combinational equivalence or mapped synthesis **does not** establish integrated timing closure, an equal-consumed-area comparison, power, or GPU speedup. The full subsequent gate requires a *separately frozen* matched reroute of the original and trial V296 implementations and independently optimized serial one-hot, same 3.5 ns/+50 ps setup/0 hold/zero cap-slew-DRC constraints, area accounting, RC sensitivity and workload tests. No relaxation of the failed original physical result.
5. Report failures and negative results. Keep existing prospective GPU holdouts sealed. Never force-push, merge or modify another active research branch.

## Rationale
The original critical setup paths traverse scheduler state -> issue selection -> bank arbitration -> RF port selection -> executed-data register. Existing path-budget forensics ruled out buffer-only closure. This trial targets combinational logic topology and specifically replaces procedural serial hit-count accumulation with explicit pairwise hit detection and a threshold-two predicate. It may fail; only physically extracted measurements can adjudicate it.
