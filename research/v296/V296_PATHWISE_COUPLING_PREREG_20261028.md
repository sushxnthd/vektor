# V296 pathwise coupling falsification: preregistered boundary (2026-10-28)

**Mechanism:** V296 pairwise bank admission versus strongest V295 optimized serial admission. This is a negative test of the integrated same-clock throughput claim, not a replacement mechanism. The only active physical repair remains the frozen symmetric upstream experiment, Actions #40718719600. Its SHA-pinned jobs have read-only repository permissions; this new non-workflow file does not change or restart those jobs.

**Frozen hypothesis before this new simulation:** With identical four-slot issue, two read ports per bank, one shared write port, 32 warps, same clock, same operand latency, identical deterministic arbitration priority and one physical slice, both designs are pathwise identical on *every* external demand trace. Hence the architecture throughput gain is exactly zero for every compatibility probability, mask overlap, hotspot correlation, bandwidth pressure and occupancy level. This is an **impossibility boundary**, not a positive breakthrough. Only physical frequency, energy, or a genuine slice-count difference can rescue an advantage. No frequency or power advantage is currently measured.

**Independent tests:** Implement serial's once/twice bitmap and pairwise's earlier-accepted operand-count algorithms independently. First exhaust 104,976 canonical four-request cases (3 bank IDs across eight operands, 16 valid patterns) and assert two-port safety. Then simulate two closed-loop schedulers on the same *exogenous counter-hashed* arrival/readiness/bank stream. Track per-warp next-ready state, round-robin cursor, per-cycle accepted IDs, read traffic, collision attempts and shared issue bandwidth. Compare entire accepted-ID traces via per-cycle assertions, not only sample means. Use four fixed seeds (1701, 1709, 1723, 1741), 5,000 cycles each, 32 warps and 4 slots.

**Frozen regimes, all predicted no-win:** (1) uniform banks, high readiness, B=4, L=1; (2) concentrated hot bank with same-bank operand correlation, B=4, L=1; (3) shared-port bottleneck B=1, L=2; (4) low readiness and latency L=5; (5) time-varying bursty hotspot/readiness. All should give exactly equal accepted waves, per-cycle traffic and state trajectories. Compare reported compatibility/overlap indicators to ensure the regimes are non-identical. A deliberately incorrect same-bank pairwise mutant must diverge in the hotspot regime; otherwise the test is not discriminating.

**Decision:** Any genuine mismatch requires investigation of implementation or assumptions, not selective reporting. If all tests pass, they add end-to-end closed-loop support for the already established equal-admission theorem and strengthen the kill case against an arbitration-throughput claim. These tests are synthetic and do not establish physical signoff, power, real GPU throughput or novel positive law. Do not retune regimes after seeing results. No changes to Kernellum PR #119 or its holdouts.
