## New measured local sensitivity

For the finite change of **+5 fF on every output port**, the V296 worst
setup slack changes **-0.009 ps**, and the serial control changes **-0.008 ps**.
The observed *two-point secants* are -0.0018 and -0.0016 ps/fF respectively;
the candidate's relative setup advantage changes by -0.001 ps
(-0.0002 ps/fF). Neither cell area changes to reported precision.

This is a useful **negative sensitivity result**: the specified external
output loading does not materially erode the candidate's measured controller
advantage in the tested 5–10 fF interval. It does **not** establish that the
critical path is exclusively internal; endpoint-specific path attribution
requires reports not extracted by this two-point analysis. It does **not**
bound the effect of longer wires, placement seeds, larger loads, corners,
switching power or full-tile integration. No statistical confidence interval
or extrapolated load threshold is inferred from two points.

## Predictive tile boundary and next falsification

The existing `tile_throughput_boundary.py` remains the predictive boundary:
`T = min(admitted_ops_per_cycle / max(controller_period, other_tile_period),
bandwidth_GBps / bytes_per_op)`. V296 and serial one-hot are functionally
equivalent; at unchanged clock, ports, occupancy and resource allocation,
**issue-throughput improvement is exactly zero**. A tile-level throughput
win requires the controller to constrain the baseline clock, a demonstrably
shorter *integrated* candidate tile period, and sufficient bandwidth. This
positive law has **not** been validated on unseen workload traces. The
frozen win/no-win workload regimes remain sealed.

**Next decisive physical science:** run independent placement/clock-tree seed
replication under identical constraints and compare all seeds, including
failures. Then measure an actual tile critical path and equal-resource
integration; do not convert 325.618 ps controller slack advantage into
a GPU frequency claim. Measure matched switching/power and trace-level
traffic before any performance claim. V287 stays retired; V296 remains the
sole provisional mechanism. No RTX-5090-equivalence claim is supported.
