# V293 retirement — equal-resource control equivalence (2026-10-23)

**Decision: RETIRE. Evidence class E0 structural/software.** No characterized STA, power, layout, or GPU throughput claim.

## Decisive comparison

The V293 local mechanism is a four-bank, one-entry-per-bank, direct-mapped bypass cache. A conventional banked operand cache with the same four entries, tag/data width, bank index, RF ports and invalidation semantics is **the same state machine**. The independent reference checker contains both policies and verifies equality for every tested access. Therefore the claimed physical locality benefit is also available to the equal-budget banked control. No distinct architectural improvement remains.

Software traces generated by independent deterministic Python checker, not silicon benchmarks. Predictions of hit rates pass, but the equal-budget banked baseline erases the distinct mechanism claim.

Energy boundary (still conditional on unmeasured capacitances):
E_global-E_local = (h_local-h_global) E_RF + h_global E_global_hit - h_local E_local_hit + C_global-C_local.
Against identical banked control, every term cancels exactly.

## Physicality

Paired local/global RTL, directed testbench and CI were committed; CI run 39885608730 was triggered. The RTL uses 32-bit demonstrator entries; Vektor wave32 operands are 1024 bits, so these cannot support tile-level PPA claims. CI generic synthesis is not Nangate45 STA. There is no clean max-cap/slew, characterized area/timing, dynamic power, wire-length sweep, or integrated tile proof. Do not reopen V293 merely to refine a failed novelty claim.

## Prior art

- BOW, MICRO 2020, DOI 10.1109/MICRO50266.2020.00084, studies operand bypass and RF energy.
- Memento, ISCA 2024, DOI 10.1109/ISCA59077.2024.00075, studies RF caching and scheduling.
- Banked and sub-core-partitioned register files are established GPU design techniques.

## Architecture consequence

No change to integrated V-Tile. The result is a falsification of distinct improvement against a banked equal-resource baseline, not proof that local caching is physically inferior to global caching.
