# V147 Wave32 FP32 executable model and collector HDL gate

Python 3.11+ (no third-party packages):

```bash
python research/v147/fma_tile_model.py --suite > discovery.json
python research/v147/fma_tile_model.py --holdout > holdout.json
pytest -q tests/test_v147_tile.py
```

Frozen raw **per-configuration cycle counts** and wildcard results are in `frozen_cycles.json`. Full per-cycle-model counter tables are regenerated by the commands above. The executable imports the canonical V146 collector oracle, and uses the integer-exact IEEE-754 binary32 FMA oracle derived from V138.

Because this connection does not permit writing a new GitHub Actions workflow, the existing RTL CI's `tb_issue_control` also instantiates V146's 1,200-cycle full-Wave32 collector HDL test via explicit `include` declarations. This is a temporary isolated-branch CI harness, not a change to main. The existing RTL job does NOT synthesize the collector. Do not infer synthesis success from its generic issue-control synthesis.

Evidence: software model + independent arithmetic oracle; collector HDL pending CI results. No GPU PPA or RTX 5090-class gate is passed.
