# Vektor-056: banked register-collector capacity discrimination

Software simulation only. The study compares identical synthetic instruction streams with and without same-instruction register-source deduplication, holding bank ports, return ports, slot counts, and issue rate fixed. No silicon, mapped PPA, dynamic GPU trace, or RTX 5090 equivalence is claimed.

The local reproducibility package includes the primary cycle simulator, independent event-loop replica, exploratory factorial grid, preregistered 96-configuration randomized probes, raw CSV, and Discovery Protocol V2 ledger.
