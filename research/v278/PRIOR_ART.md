# V278 novelty gate: prior art

US Patent 8,555,035 (2013), 'Conflict-free register allocation using a multi-bank register file with input operand alignment', explicitly describes compiler bank assignment, graph coloring, pre-allocation and post-allocation schemes, plus occupancy, copying and bank-balance trade-offs. The basic V278 compiler remapping mechanism is therefore NOT novel. See https://www.freepatentsonline.com/8555035.html .

The V278 training boundary may still guide integration of an established compiler optimization, but cannot support a breakthrough claim. Novelty requires a distinct law/mechanism and matched hardware evidence. No user laptop or paid tools were used.
