# V289 ACTIVE: dependency-critical register-bank admission (E0 hypothesis)
Date: 2026-10-23. Sole active kernel after V288 was retired as equivalent to a conventional same-budget operand cache.

1. **Bottleneck law:** At a single-read-port bank, total grants are invariant to request ordering; however a serial dependency chain can determine kernel makespan. If L critical reads each encounter an older noncritical same-bank request with probability p, the ideal expected critical-path wait saved is L*p cycles, minus added control delay and any noncritical work becoming critical. This is a hypothesis under independent conflicts, not a measured law.
2. **Exact mechanism:** Four queued operand requests, two single-port banks. For each bank, select the oldest request among those marked dependency-critical; if none, select the oldest request. One compiler/scoreboard-supplied criticality bit per request; no extra RF ports, storage or buffering.
3. **Strongest equal-budget controls:** Age-first maximal bank grants with the same two ports, four request slots and one priority metadata bit per slot (encoded as an urgency/age flag); additionally compare criticality-aware age scheduling and an oracle DAG-critical-path scheduler. If controls match, retire.
4. **Predicted win/loss boundary:** Win only when same-bank contention overlaps long serialized dependence chains, the criticality bit is accurate, and issue/control delay does not consume saved stalls. No win for independent requests or conflict-free bank accesses. Possible loss when falsely tagged critical requests delay the actual critical path.
5. **Smallest RTL:** One 4-request, 2-bank combinational grant selector with critical-first priority. Identical-age and bank-port control provided. No RF storage changes.
6. **Physical proxy:** Nangate45 mapped area, max-cap/slew, STA delay at matched loads; criticality fanout switching; area-normalized frequency and cycle time. No PPA claim until measured.
7. **Workload metrics:** DAG makespan, bank grants/cycle, critical-path waiting cycles, noncritical starvation, bank reads, instruction issue throughput, traffic, across compute/memory/divergent traces with identical hardware resources.
8. **Decisive falsification:** If age/urgency-matched control or DAG-oracle control erases makespan gain, if false criticality causes severe tails, or if characterized delay/area erases gain, retire immediately.
9. **Frozen unseen predictions (not yet evaluated):** WIN: 2-bank, single-port, long dependent chain with 0.5 same-bank conflict probability and accurate criticality -> predicted reduction in critical-chain wait; NO WIN: no same-bank conflicts, all requests independent -> identical grants and completion time. These are qualitative until a workload model is frozen; no numerical success claim.
10. **Architecture consequence:** Only upon passing physical and unseen workload gates consider a criticality bit in V-Tile operand collector request arbitration. No integrated tile modification.

**Novelty risk:** Criticality-aware scheduling and bank-aware arbitration are established fields. This is a narrow, falsifiable integrated GPU microarchitecture experiment, not a new-principle claim. V287 and V288 retired; V153/V156 FP32 cutset electrically disqualified. No RTX 5090 equivalence claim.
